## Built on MTG2A04_L02_S01's engine
The game shell is MTG2A04_L02_S01's, unchanged: the 1333×750 stage fitted to every screen, the landing (room card,
sticker title, waving Swiftie, speaker, round play button that waits for the greeting and pulses), the header band
with Swiftie's moods, the yellow → button, the standard SFX (`assets/sfx/`) and background music (`bgm.ogg`, ducked
under every VO), the peek phase-transition gate ("चलिए, शुरू करते हैं!" / "चलिए, साथ में करें!" / "अब आपकी बारी!"),
confetti, the nudge hand, the asset loader, xAPI / SwiftPAL bridge, the end screen. Only MTG2A04's measuring screens
and their art are gone; in their place is the **place-value addition kit** (`app.js` `PVK` + `PVModules`, CSS
`[pv kit]`), shared word for word with **MTG2A01_L03_S02** — the two games differ only in their `card.json`.

`app.js`, `style.css` and `index.html` are generated by `../pv-addition-kit/assemble.py` from MTG2A04's files + the
kit; `card.json` by `../pv-addition-kit/lessons.py`. Edit there, then rebuild (see "Rebuilding").

## Rebuilding
```
python ../pv-addition-kit/lessons.py        # card.json + tools/vo_script.json (both games)
python tools/build_vo.py                     # renders any VO line not yet on disk (edge-tts; internet)
python tools/make_avatars.py                 # the people
python ../pv-addition-kit/assemble.py        # app.js / style.css / index.html (both games)
node tools/gen_asset_sizes.js                # the preload manifest - after ANY asset change
```
Dev: `index.html?slide=N` opens slide N directly; `?dev=1` adds the slide navigator.
